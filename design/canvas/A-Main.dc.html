MLX Swiftでトークンをストリーミングしながら、SwiftUIのテキストを滑らかに更新したい。再描画が多すぎて重くなるのを避けるには？

ポイントはトークンごとにViewを更新しないことです。生成ループ側でバッファし、約30msごとにまとめてMainActorへ流すと、体感の滑らかさを保ったまま再描画を大幅に減らせます。

StreamBuffer.swift
@MainActor final class StreamBuffer: ObservableObject { @Published private(set) var text = "" private var pending = "" private var flushTask: Task<Void, Never>? func append(_ token: String) { pending += token guard flushTask == nil else { return } flushTask = Task { try? await Task.sleep(for: .milliseconds(30)) text += pending; pending = ""; flushTask = nil } } }
  • Text を差分描画できるよう、長文は段落単位に分割して LazyVStack に並べる
  • スクロール追従は末尾アンカーのみ更新し、ユーザーがスクロールしたら一時停止する
